# 🕹️ central-hub // sanxnn

> Primary link router and central gateway matrix deployed at [sanxnn.katanya.dev](https://sanxnn.katanya.dev). Built with light retro brutalism, lightweight execution structures, and zero layout clutter.

---

## 🎮 Arcade Core Features

* **📦 Monolithic Single-File Architecture** – Entirely contained within a production-ready, highly optimized `index.html` built with Tailwind CSS.
* **⏳ 3-Second Pure Pixel Loading** – Custom lightweight light-themed initialization layer featuring an 8-bit monochromatic spinner with stepped frame rotations.
* **🪙 Interactive Coin Detonator System** – Embedded custom Mario-style arcade clicker box that streams dynamic state changes to the UI.
* **⚠️ Full-Screen Explosion Module** – Reaching exactly **100 coin clicks** triggers a full-viewport critical overload animation (`💥 KABOOM!!!`) accompanied by a programmatic chiptune sound effect before hot-rebooting the system.
* **🔊 Programmatic Chiptune Audio Engine** – Native Web Audio API synthesis utilizing raw square and triangle oscillators to generate 8-bit sound effects entirely through browser code without external `.mp3` dependencies.

---

## 🛠️ Built With

* **Tailwind CSS** – High-contrast Neo-Brutalist utility profiling and pixelated custom spatial shadows.
* **Alpine.js** – Ultra-lightweight reactive client-state management for the loading progress timeline and arcade scoring sub-systems.
* **Google Fonts** – *Press Start 2P* monospace typography injection.
